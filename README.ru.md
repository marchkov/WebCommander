# WebCommander

Двухпанельный веб-файловый менеджер с Local и SSH/SFTP, просмотром и редактированием
текста, ZIP-архивами и независимым терминалом в каждой панели.

[English README](README.md)

## Возможности

- Просмотр, копирование, перемещение, переименование и удаление файлов и каталогов между Local и SFTP.
- **F3** — просмотр, **F4** — редактирование, **Shift+F4** — новый файл.
- **↑/↓**, **Enter**, **Backspace**, **Tab** — навигация; **F5/F6/F7/F8** — копирование/перемещение/новая папка/удаление; **Shift+F6** — переименование.
- **Pack to ZIP** и **Extract here** работают с бинарными файлами, пустыми каталогами и смешанным выделением.
- Подключение по SSH с паролем или ключом, управление соединениями и восстановление живых сессий после перезагрузки страницы.
- **>_** открывает локальный PTY или SSH shell; **Ctrl+T** переключает терминал активной панели.
- Скачивание файлов/каталогов и загрузка через провайдерные API с ограничением размера.

Local — файловая система **backend-сервера**, а не компьютера браузера. SSH-панели
используют POSIX-пути и SFTP-потоки через backend. Копирование и перемещение работают
между Local и SFTP, а также между SFTP-соединениями. FTP не реализован.

## Требования

- Поддерживаемый Node.js LTS и npm. Для сборки нативного терминала на Linux нужны Python, make и C++-компилятор.
- Альтернатива — Docker/Compose; см. [DEPLOY.ru.md](DEPLOY.ru.md).

## Быстрый старт

```bash
git clone https://github.com/marchkov/WebCommander.git
cd WebCommander
npm ci
cp config.example.json config.json
mkdir -p data
```

На Windows используйте `Copy-Item config.example.json config.json` и создайте
каталог `data`. Не перезаписывайте уже существующую локальную конфигурацию.

В своём `config.json` замените шаблоны логина и пароля, задайте случайный session
secret длиной не менее 32 символов и настройте пути. **Только для локального HTTP**
задайте `auth.cookieSecure=false`. Пример намеренно не запускает production без
настройки. Локальные config и `.env*` исключены из Git; публикуются только безопасные
примеры. Переменные `WC_*` перекрывают config. Node не загружает `.env` автоматически.

Локальный запуск со собранным интерфейсом:

```bash
npm run build
bash start.sh
```

На Windows используйте `start.bat`. Откройте `http://localhost:3001` и войдите
с настроенными учётными данными. Скрипты по умолчанию используют development и
loopback. Production, HTTPS, proxy и сессии описаны в [DEPLOY.ru.md](DEPLOY.ru.md).

Для разработки запустите `node server/index.js` и `npm run dev` в разных терминалах,
откройте `http://localhost:3000`. При недоступном backend клиент может перейти на
демонстрационные данные; действия demo не изменяют реальные файлы.

## Поведение

**F3** открывает редактор только для чтения, без сохранения. **F4** и двойной клик
по файлу открывают Edit. Ctrl/Cmd-клик сохраняет множественное выделение.
**Ctrl+F** открывает Connections; **Insert** переключает выделение и двигает курсор.
Навигация панели не меняет каталог запущенного терминала; повторное открытие или
Reconnect запускает shell в актуальном каталоге панели.

Переименование, создание файла, загрузка и создание ZIP не перезаписывают
существующие элементы. Копирование/перемещение и распаковка сообщают о конфликтах
и допускают явную перезапись файлов, но не замену файла каталогом или наоборот.
Неудачная распаковка может оставить уже извлечённые файлы. Лимиты загрузки и
расширения описаны в [DEPLOY.ru.md](DEPLOY.ru.md); существующие файлы редактируются
независимо от ограничений расширений.

Восстановление SSH требует прежнюю живую веб-сессию и работающий backend.
Перезапуск backend завершает соединения в памяти. Logout закрывает только SSH
соединения своей веб-сессии. Подробности — в [SSH_GUIDE.ru.md](SSH_GUIDE.ru.md).

## Безопасность

Для production нужны HTTPS, явные учётные данные и случайный session secret.
Запускайте backend без повышенных привилегий и ограничивайте allowedPaths/blockedPaths.
Изменяющие браузерные запросы и вход проверяют Origin/Fetch Metadata; SSH-соединения
принадлежат веб-сессиям. Распаковка блокирует выход за каталог, загрузка проверяет
имя, путь, размер и расширение.

**Терминал выполняет команды с правами пользователя backend или удалённого SSH.**
Проверки LocalProvider ограничивают начальный каталог, но **не изолируют** shell
и файловую систему. Приложение предназначено для доверенных пользователей.
Текущие ограничения: пароли в конфигурации хранятся открыто, session store работает
в памяти по явному opt-in, проверка/закрепление SSH host key не реализованы.
Перед внешним доступом прочитайте [DEPLOY.ru.md](DEPLOY.ru.md).

## Проверки

```bash
npm ci
npm run typecheck
npm run build
node --test server/*.test.js server/providers/*.test.js server/services/*.test.js tests/*.test.cjs
npm audit
```

Для нативных PTY-тестов задайте `WC_TEST_REAL_PTY=1`; CI включает их.
На Windows тесты symlink могут пропускаться при отсутствии привилегий.
SFTP проверяется адаптерами, без внешнего SSH-сервера.
